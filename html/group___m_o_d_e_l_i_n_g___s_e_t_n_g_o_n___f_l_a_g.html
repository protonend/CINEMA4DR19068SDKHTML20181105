Macro Definition Documentation

◆ MODELING_SETNGON_FLAG_EMPTY

#define MODELING_SETNGON_FLAG_EMPTY

No flags.

◆ MODELING_SETNGON_FLAG_TRIANGULATE

#define MODELING_SETNGON_FLAG_TRIANGULATE

Force the N-gon to be created as its polygons (similar to the MODELING_COMMIT_TRINGONS but for a single N-gon).

◆ MODELING_SETNGON_FLAG_FIXEDQUADS

#define MODELING_SETNGON_FLAG_FIXEDQUADS

Similar to MODELING_SETNGON_FLAG_TRIANGULATE but force the N-gon to create a fixed set of quads. Used for extrude (faster than triangulation).

◆ MODELING_SETNGON_FLAG_NGONQUADS

#define MODELING_SETNGON_FLAG_NGONQUADS

Similar to MODELING_SETNGON_FLAG_FIXEDQUADS except the quads are used to form the N-gon. Used for extrude.

◆ MODELING_SETNGON_FLAG_QUADS

#define MODELING_SETNGON_FLAG_QUADS

As with the MODELING_SETNGON_FLAG_TRIANGULATE but tries to create quads.

◆ MODELING_SETNGON_FLAG_UNION

#define MODELING_SETNGON_FLAG_UNION

Mark the N-gon to use the same data during tag translation as the origin N-gon.

◆ MODELING_SETNGON_FLAG_NOROTATE

#define MODELING_SETNGON_FLAG_NOROTATE

Skips an internal convex check (and rotate) so that quads remain in the same order.
