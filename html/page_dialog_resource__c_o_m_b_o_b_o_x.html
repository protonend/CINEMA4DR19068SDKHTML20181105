COMBOBOX

Definition

COMBOBOX [id]
{
  [Flags]

  CHILDS
  {
    [Child 1]
    [Child 2]
    ...
  }
}

Description

Combo boxes let the user choose among several items in a popup menu.
The combo box items are listed within the CHILDS group (note the spelling!). Each child should be formatted like this: 

id, stringidentifier;

Where id is either a number or an enum from c4d_symbols.h, stringidentifier is an identifier from the string resource file that belongs to the dialog.
Use GeDialog::SetInt32() and GeDialog::GetInt32() to access the current selection.

Flags

See Dialog Resource for a description of the common flags.

[LAYOUTFLAGS]Layout flags.
[SIZE]Manual size.

Example

COMBOBOX IDC_COMBO
{
  SCALE_H;

  CHILDS
  {
    FIRST_CHILD_ID, FIRST_CHILD_TEXT;
    SECOND_CHILD_ID, SECOND_CHILD_TEXT;
  }
}
