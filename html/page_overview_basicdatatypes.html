Data Types Overview

About

This chapter describes the most important data types of the Cinema 4D API.

Primitive Mathematical Datatypes

For mathematical operations primitive and complex data types are available:

  • The basic data types Bool, Char, Int and Float. See Primitive Data Types Manual.
  • Functions to perform basic mathematical operations. See Mathematical Functions Manual.
  • Vector is Cinema 4D's three component vector class. See Vector Manual.
  • Matrix is Cinema 4D's matrix class. See Matrix Manual.
Note
Only primitive data types can be used as static variables.

Data Containers

Cinema 4D offers two generic data containers:

  • A GeData container is used to store data of different types. See GeData Manual.
  • A BaseContainer container can store multiple values of different types. See BaseContainer Manual.

Strings

Cinema 4D offers a generic string class and also a special class to handle filenames:

  • String is Cinema 4D's generic string class. See String Manual.
  • Filename is a specialized class to handle filenames and paths. See Filename Manual.

Miscellaneous

Further relevant data types are:

  • BaseLink is a class to store references to other elements. Use a BaseLink to reference any scene element instead of storing the object pointer. See BaseLink Manual.
  • BaseTime is a class that is used to define the time within a document. See BaseTime Manual.
Note
More complex and specialized data types are based on CustomDataType.
