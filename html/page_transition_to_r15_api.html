Transition to Cinema 4D R15 API

Cinema 4D R15 API brings important naming changes:

  • If your plugin runs and does not need a recompile, nothing needs to be done.
  • If your plugin is recompiled you can either use the old naming scheme in order to keep changes to a minimum or adapt your code to the new one.
