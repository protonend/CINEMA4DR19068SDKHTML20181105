Color Swatches Overview

About

Color swatches are a system to handle colors or color groups. These color groups can be stored with Cinema 4D itself, a BaseDocument or a preset.

  • Color data is stored in a ColorSwatchData object, see ColorSwatchData Manual.
  • The ColorSwatchData object stores multiple ColorSwatchGroup objects, see ColorSwatchGroup Manual.
  • Additional color utility functions are available, see Color Functions Manual.
