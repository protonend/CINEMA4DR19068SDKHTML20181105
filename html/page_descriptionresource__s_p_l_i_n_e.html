SPLINE

Definition

SPLINE [id]
{
  [Common flags]
  [SHOWGRID_H;]
  [SHOWGRID_V;]
  [GRIDSIZE_H n;]
  [GRIDSIZE_V n;]
  [EDIT_H;]
  [EDIT_V;]
  [LABELS_H;]
  [LABELS_V;]
  [X_MIN xmin;]
  [X_MAX xmax;]
  [X_STEPS sx;]
  [Y_MIN ymin;]
  [Y_MAX ymax;]
  [Y_STEPS sy;]
  [HAS_PRESET_BTN;]
  [HAS_ROUND_SLIDER;]
  [MINSIZE_H x;]
  [MINSIZE_V y;]
  [X_MIN_TEXT xmin_text;]
  [X_MAX_TEXT xmax_text;]
  [Y_MIN_TEXT ymin_text;]
  [Y_MAX_TEXT ymax_text;]
  [X_TEXT x_text_text;]
  [Y_TEXT y_text_text;]
}

Description

Represents SplineData objects in a container, rendered with SplineCustomGui.

Flags

REFUSE idlist;The node types to refuse, separated with semi-colons.
SHOWGRID_H;Show horizontal grid.
SHOWGRID_V;Show vertical grid.
GRIDSIZE_H n;Horizontal grid steps.
GRIDSIZE_V n;Vertical grid steps.
EDIT_H;Edit field for horizontal value.
EDIT_V;Edit field for vertical value.
LABELS_H;Horizontal labels.
LABELS_V;Vertical labels.
X_MIN xmin;Minimum X value.
X_MAX xmax;Maximum X value.
X_STEPS sx;X step for edit control.
Y_MIN ymin;Minimum Y value.
Y_MAX ymax;Maximum Y value.
Y_STEPS sy;Y step for edit control.
HAS_PRESET_BTN;Show preset button.
HAS_ROUND_SLIDER;Show tension slider.
MINSIZE_H x;Minimum horizontal size.
MINSIZE_V y;Minimum vertical size.
X_MIN_TEXT xmin_text;Minimum X value text.
X_MAX_TEXT xmax_text;Maximum X value text.
Y_MIN_TEXT ymin_text;Minimum Y value text.
Y_MAX_TEXT ymax_text;Maximum Y value text.
X_TEXT x_text_text;X text.
Y_TEXT y_text_text;Y text.

Example

SPLINE SPLINEDEFORMEROBJECT_SPLINECONTROL
{
SHOWGRID_H;
SHOWGRID_V;
GRIDSIZE_H 8;
GRIDSIZE_V 8;
HAS_PRESET_BTN;
MINSIZE_H 120;
MINSIZE_V 90;
EDIT_H;
EDIT_V;
LABELS_H;
LABELS_V;
HAS_ROUND_SLIDER;
X_MIN 0;
X_MAX 100;
Y_MIN 0;
Y_MAX 100;
X_STEPS 1;
Y_STEPS 1;
}
