Library » Big Integer

#include <lib_big_integer.h>

Detailed Description

Class to manipulate big integer values.

Note
Has to be created with Alloc() and destroyed with Free(). Use AutoAlloc to automate the allocation and destruction based on scope.

◆ SetRandomPrime()

Bool SetRandomPrime ( maxon::Int  bitCount,
maxon::UInt  certainty,
SecureRandomProvider  provider = nullptr 
)

Assigns a random prime number value to the BigInteger. The number is always positive, odd and the (bitCount - 1) bit will be set.

Parameters
[in]bitCountThe number of bits to set, must be greater than 1.
[in]certaintyThe generated number is a prime number with a probability of 1 - 0.5 * certainty. Must be greater than 0.
The execution time of the function raises with the certainty.
[in]providerA secure random provider that can be used with SecureRandom. If nullptr is passed an insecure default provider is chosen.
Returns
true if successful, otherwise false.
