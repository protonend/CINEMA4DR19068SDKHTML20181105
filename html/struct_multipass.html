#include <c4d_shader.h>

Detailed Description

These values have to be filled by custom illumination models:

  • Standard: diffuse, specular, shadow
  • VP: vp_diffuse, vp_specular, vp_shadow, vp_illumination (later vp_radiosity and vp_caustics) These values have to be filled/processed by shaders:
  • Filled: vp_mat_color, vp_mat_luminance, vp_mat_transparency, vp_mat_reflection vp_mat_environment, vp_mat_specularcolor vp_mat_specular, vp_mat_diffusion
  • Processed: diffuse, specular, vp_ambient

◆ bmp

VPBitmap** bmp

Internal. An array of @ref cnt VPBitmaps.

◆ ind

Int32* ind

The index into the components for all layers.
Examples:

  • Standard rendering:
    cnt == 1
    cmp == 4 (R,G,B, Alpha)
    ind[0] = 0
    result[0..3] : R,G,B, Alpha component
  • Multilayer rendering:
    cnt == 3
    cmp == 8 (R,G,B, Alpha, Diffuse R, Diffuse G, Diffuse B, Depth Channel)
    ind[0] = 0
    ind[1] = 4
    ind[2] = 7
    result[0..7] : R,G,B, Alpha, Diffuse R, Diffuse G, Diffuse B, Depth component
