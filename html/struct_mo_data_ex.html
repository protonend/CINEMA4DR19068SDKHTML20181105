#include <c4d_baseeffectordata.h>

Detailed Description

Structure for passing cloned points around.
The data is stored in separate dynamic arrays for internal purposes in the MoData struct. The Matrices are always in local space to the object that generated/owns the particles.

See also
MoData::SetWithEx
Warning
Only kept for legacy support. Has been replaced by the MoData class.
