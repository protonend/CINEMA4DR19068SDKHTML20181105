MPThreadPool Class Reference

#include <c4d_thread.h>

Detailed Description

Multiple processor thread array. Starts each thread in the array on a separate CPU:

class MPTest : public C4DThread
{
public:
virtual void Main(void);
};
class ControlThread : public C4DThread
{
public:
virtual void Main(void)
{
MPThreadPool mp;
Int32 i, cnt=GeGetCurrentThreadCount();
MPAlloc<MPTest> thread;
AutoGeFree<C4DThread*> list = NewMemClear(C4DThread*, cnt);
if (!list || !thread.Init(cnt))
return;
for (i=0; i<cnt; i++)
{
list[i]=&thread[i];
}
if (!mp.Init(*this,cnt,list)) =
return;
if (!mp.Start(THREADPRIORITY_BELOW))
return;
mp.Wait();
}
};
ControlThread ct;
ct.Start(THREADMODE_SYNCHRONOUS);
Warning
MP threads must not use any OS functions. This is strictly forbidden. The only system calls allowed are memory allocations/freeings.

Initializes the multi-processor threads.

Parameters
[in]parentThe control thread that will manage the multiple threads. A control thread is necessary so this parameter cannot be set to nullptr.
[in]countThe number of threads to create: 1 <= count <= GeGetCurrentThreadCount()
It does not need to match the actual GeGetCurrentThreadCount() on the machine. However for best speed GeGetCurrentThreadCount() should be used.
[in]threadPointer to an array of pointers to C4DThread structures that hold the threads to create. The caller owns the pointed threads array.
Returns
true if successful, otherwise false.
