Detailed Description

Pose morph tag storing the morph data.

Note
Has to be created with Alloc() and destroyed with Free(). Use AutoAlloc to automate the allocation and destruction based on scope.
See also
CAMorphNode for an example.

◆ ExitEdit()

Bool ExitEdit ( BaseDocument *  doc,
Bool  noapply 
)

Must be called before doing anything to a morph tag.
For example, if the user is in Edit mode and making changes these are not applied to the morph until this function is called.
So if this function is not called those changes will be lost. Set apply to true if any user changes should be stored. This is normally the case.

Parameters
[in]docThe document. The caller owns the pointed document.
[in]noapplySet to false if any user changes should be stored, otherwise set to true.
Returns
true if successful, otherwise false.
