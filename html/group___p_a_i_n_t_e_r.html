◆ PAINTER_SAVETEXTURE

#define PAINTER_SAVETEXTURE

Save texture(s).
If doc!=nullptr all textures associated with doc are saved.
If tex!=nullptr only tex is saved, otherwise all textures are saved.

Note
Returns true if successful, otherwise false.
