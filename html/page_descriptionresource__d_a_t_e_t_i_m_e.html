DATETIME

Definition

DATETIME [id]
{
  [Common flags]
  [TIME_CONTROL;]
  [DATE_CONTROL;]
  [TIME_NOW;]
  [DATE_TODAY;]
  [DATETIME_COLUMN;]
  [CLOCK_OPEN;]
  [CALENDAR_OPEN;]
  [COMPACT_MODE;]
  [COMPACT_OPEN;]
}

Description

Represents DateTimeData objects in a container. Rendered with DateTimeControl as a selector for a date and/or a time.

Flags

TIME_CONTROL;Show the time part.
DATE_CONTROL;Show the date part.
TIME_NOW;Provide a "Now" button.
DATE_TODAY;Provide a "Today" button.
DATETIME_COLUMN;Render the calendar and the clock in one column.
CLOCK_OPEN;Show the clock initally.
CALENDAR_OPEN;Show the calendar initially.
COMPACT_MODE;Compact layout.
COMPACT_OPEN;Expanded.

Example

DATETIME SKY_DATE_TIME { PARENTCOLLAPSE; NOW_BUTTON; ANIM MIX; OPEN; }
