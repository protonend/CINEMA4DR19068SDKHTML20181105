About

NodeData based plugin classes can implement NodeData::GetDDescription(). This allows to dynamically add parameters to the element's parameter description. This description is then used by Cinema 4D to define the parameters that are displayed in the Attribute Manager.

NodeData::GetDDescription() corresponds to C4DAtom::GetDescription().

Note
NodeData::GetDDescription() will be called when the DIRTYFLAGS_DESCRIPTION flag of an object is set.

Usage

When NodeData::GetDDescription() is called it is supposed to fill the given Description object.

// This example adds a new parameter description to the object.
virtual Bool GetDDescription(GeListNode* node, Description* description, DESCFLAGS_DESC& flags)
{
if (!node || !description)
return false;
// load the description of this type (always the first thing to do in GetDDescription)
if (!description->LoadDescription(node->GetType()))
return false;
const DescID* singleid = description->GetSingleDescID();
// add a parameter description
DescID cid = DescLevel(1003, DTYPE_REAL, 0);
// check if this parameter ID is requested (NOTE: this check is important for speed)
if (!singleid || cid.IsPartOf(*singleid, nullptr))
{
// define the new parameter description
BaseContainer realParameterData = GetCustomDataTypeDefault(DTYPE_REAL);
realParameterData.SetString(DESC_NAME, "A new parameter");
// set the new parameter
if (!description->SetParameter(cid, realParameterData, ID_OBJECTPROPERTIES))
return true;
}
flags |= DESCFLAGS_DESC_LOADED; // Don't forget to set this flag, when you are done!
return SUPER::GetDDescription(node, description, flags);
}

The arguments of the function are:

  • The node itself.
  • The Description object to fill.

  • Some Flags. The possible values are:

    • DESCFLAGS_DESC_LOADED: Set if elements have been added to the description, either by loading or manual addition.
    • DESCFLAGS_DESC_MAPTAGS: If set, the object description will also contain the tag's descriptions (as sub-containers).
    • DESCFLAGS_DESC_NEEDDEFAULTVALUE: Set if "Reset to Default" was called by the user.

    Details on how to handle a Description are described in Description Manual and Description Settings Manual.
