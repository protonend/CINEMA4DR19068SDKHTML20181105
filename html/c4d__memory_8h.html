◆ IsAlienMem()

Bool IsAlienMem ( void *  p)

Checks if a memory block was allocated by Cinema 4D or not.

Note
Some linked libraries call new/delete during startup, before the Cinema 4D OS is initialized.
This is a mess, because later calls to new will allocate through Cinema 4D's memory routines.
Works for allocations done by new and NewMemClear().
Parameters
[in]pAddress of the memory block. The caller owns the pointed memory.
Returns
true if memory block was allocated by Cinema 4D, otherwise false.
