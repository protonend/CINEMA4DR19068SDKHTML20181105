Motion Tracker Overview

About

The Motion Tracker API provides read-only access to properties of the Motion Tracker object. It is possible to access information on the loaded footage and on the created 2D tracks. The API is defined in lib_motiontracker.h.

  • A MotionTrackerObject represents a Motion Tracker object, see MotionTrackerObject Manual.
  • A MtFootageData object stores information on the loaded video footage, see MtFootageData Manual.
  • Mt2dTrackData and further classes provide access to the 2D tracking data, see Mt2dTrackData / Mt2dTrack / MtData Manual.
