GRADIENT

Definition

GRADIENT [id]
{
  [Common flags]
  [COLOR;]
  [ALPHA;]
}

Description

Represents Gradient objects in a container.

Flags

COLOR;Editable color gradient.
ALPHA;Editable alpha gradient.

Example

GRADIENT TURBULENCESHADER_COLOR { ICC_BASEDOCUMENT; }
