Detailed Description

template<typename K, typename V, typename HASH = maxon::DefaultHash, typename GET_KEY = maxon::HashMapKeyValuePair, typename ALLOCATOR = maxon::DefaultAllocator>
class maxon::HashMap< K, V, HASH, GET_KEY, ALLOCATOR >::Entry

Class used for entries of the HashMap. The entries of a bucket are stored as a singly linked list, you can loop over this list via GetNextInBucket().
