GUI Messages

The whole GUI in Cinema 4D is based on elements sending various GUI messages to each other. Fortunately most of this has been encapsulated in the SDK, so that dialogs etc. behave like ordinary C++ classes.
However, sometimes it can be useful to participate directly in the message exchange, for example when writing custom components.

This document covers all GUI messages that are not private, with exception for Input Events and Drag and Drop.

Distribution

GUI messages are sent by Cinema 4D to GeDialog::Message() and GeUserArea::Message().
To send messages to dialogs call these functions or use GeUserArea::SendParentMessage().
To send messages directly to dialog elements, use GeDialog::SendMessage() with the dialog element's ID.

Note
Make sure to pass along any messages to the parent class that you do not process.

Structure

The GUI messages are passed as BaseContainer objects. The message ID is stored in the ID of the container, retrieved with bc->GetId().
A result container is also passed with each message to return values.

Note
Generally return true in the message function if you took care of the message, and false otherwise.
