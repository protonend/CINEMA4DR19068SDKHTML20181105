◆ MAXON_MISC_DEPRECATED_ENUMVALUE

#define MAXON_MISC_DEPRECATED_ENUMVALUE (   name,
  value,
  reason 
)

Use MAXON_MISC_DEPRECATED_ENUMVALUE to mark an enum value being deprecated. Used for enums with fixed values. This macro is processed by MSVC, Clang, GCC and Doxygen.

Example:

enum class COLORS
{
RED,
GREEN,
BLUE,
MAXON_MISC_DEPRECATED_ENUMVALUE(BROWN, 100, "Color for brown objects. Use red from now on")
MAXON_MISC_DEPRECATED_ENUMVALUE(YELLOW, 200, "Color for yellow objects. Use blue from now on")
};

◆ MAXON_MISC_DEPRECATED_ENUMVALUE_AUTO

#define MAXON_MISC_DEPRECATED_ENUMVALUE_AUTO (   name,
  reason 
)

Use MAXON_MISC_DEPRECATED_ENUMVALUE_AUTO to mark an enum value being deprecated. Used for enums with auto generated value. In this case the enum must not be moved. This macro is processed by MSVC, Clang, GCC and Doxygen.

Example:

enum class COLORS
{
RED,
MAXON_MISC_DEPRECATED_ENUMVALUE_AUTO(BROWN, "Color for brown objects. Use red from now on.") // gets value RED + 1
GREEN,
MAXON_MISC_DEPRECATED_ENUMVALUE_AUTO(YELLOW, "Color for yellow objects. Use blue from now on.") // gets value GREEN + 1
BLUE,
};

◆ MAXON_SWITCH_FALLTHROUGH

#define MAXON_SWITCH_FALLTHROUGH

This statement needs to be used for any case in a switch the contains code, but does not call break. An example:

switch(condition)
{
case 0:
...do something...
MAXON_SWITCH_FALLTHROUGH
case 1:
...do something...
break;
}

◆ MAXON_OPERATOR_MOVE_ASSIGNMENT

#define MAXON_OPERATOR_MOVE_ASSIGNMENT (   TypeName)

This statement automatically creates a move assignment operator from an existing move constructor. It needs to be written in the public: section. An example:

class MyClass
{
MAXON_DISALLOW_COPY_AND_ASSIGN(MyClass);
public:
MAXON_OPERATOR_MOVE_ASSIGNMENT(MyClass);
...

◆ CriticalOutput

#define CriticalOutput (   fmt,
  ... 
)

CriticalOutput outputs text into the console. The output is visible in debug builds or in a release build when the debug console with critical output is activated. It should only be used to output unexpected, critical conditions that would most likely result in instability, e.g. an illegal array access or corrupt object structure. It can also be used for unexpected events, e.g. if a necessary module cannot be initialized. It automatically shows header information and adds a line break. It automatically stops the debugger if present. The full printf syntax can be used for the format string. THREADSAFE.
