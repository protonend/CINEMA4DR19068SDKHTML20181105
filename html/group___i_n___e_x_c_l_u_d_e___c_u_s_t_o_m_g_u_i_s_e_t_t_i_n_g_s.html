◆ IN_EXCLUDE_FLAG_SEND_SELCHANGE_MSG

#define IN_EXCLUDE_FLAG_SEND_SELCHANGE_MSG

Bool true if the selection state should be stored in the object's data container.

◆ IN_EXCLUDE_FLAG_ENABLED_IN_TRISTATE

#define IN_EXCLUDE_FLAG_ENABLED_IN_TRISTATE

Bool true if list is should be enabled in tristate (old behavior). If false list will be disabled in tristate and it will show text "<<Multiple Values>>". Tristate is when there are several lists selected but they contain different objects.
