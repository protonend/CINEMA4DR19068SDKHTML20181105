PROTOCOL  ptype,
maxon::BaseArray< NetworkIpAddr > &  addrs,
Bool  firstMatch = true,
Bool  forceResolve = false 
)

Resolves a host name.
If the address object can be an IP address object, GetIpAddress(address, &addr, true) should be used instead.

Parameters
[in]addressThe host name to resolve.
[in]ptypePass PROTOCOL_IPV4 if the result should just contain IPv4 addresses, same for PROTOCOL_IPV6 with IPv6 address and @ref PROTOCOL_ALL for all addresses.
[out]addrsAssigned the addresses of the host name when the function succeeded.
[in]firstMatchIf true address array addrs has a maximum size of 1.
[in]forceResolveIf false use the DNS cache if the address is a host name and already known. Pass true for an automatic mode.
Returns
RESOLVERESULT_OK on success, otherwise the resolve operation failed.

◆ GetIpAddress() [1/2]

Bool GetIpAddress ( const String &  address,
NetworkIpAddr &  a,
Bool  resolve = false,
Bool  forceResolve = false 
)

Converts a host name, IPv4 or IPv6 address into an IP address object.
A port value in the address will be ignored. When the resolve option is enabled, the call blocks and waits for the DNS system when the address is a host name. e.g:

  • Sebastians-Macbook-Pro.local : DNS system used, call does block
  • 192.168.10.1 : no DNS system used, call does not block.
    Parameters
    [in]addressThe IP address or host name. If the string is a host name, resolve must be set to true otherwise the function fails.
    [out]aAssigned the IP address object.
    [in]resolvePass true to resolve the address via the DNS system.
    [in]forceResolvePass true to force resolve.
    Returns
    true if the IP address was retrieved successfully, otherwise false.

◆ SplitAddress()

Bool SplitAddress ( String  address,
String *  scheme,
String *  host,
Int32 *  port 
)

Splits a specified scheme with host name and port into its components.
Handle IPv4, IPv6 addresses and host names.

Parameters
[in]addressThe host name to split. Can optionally contain a scheme, host and port. For instance:
  • "http://127.0.0.1:8080"
  • "http://[AB:AB:AB:AB:AB:AB]:1234"
  • "192.168.10.1"
  • "Sebastians-Macbook-Pro.local:80"
[out]schemeAssigned the scheme. Can be empty if no scheme was found.
[out]hostAssigned the address/host name without port scheme and port number.
[out]portAssigned the port. If no port was found NOTOK is assigned.
Returns
true if the IP address was successfully split, otherwise false.
