Core Messages

Core message are global notifications within Cinema 4D telling the different interface parts that the scene data has changed, so that they can update their status.

Adding Events

Generally if you have made a change that needs other parts of Cinema 4D to redraw just call EventAdd().
The view system uses several comparison methods to detect if it needs to redraw the interactive plane. In the seldom case when it fails call EventAdd(EVENT_FORCEREDRAW).

If you need events that are only locally relevant (in your managers) then use SpecialEventAdd(myplugin_id). Cinema 4D does not react on those.

Distribution

Both EventAdd() and SpecialEventAdd() result in a notification in CoreMessage(). The event for EventAdd() is called EVMSG_CHANGE.
