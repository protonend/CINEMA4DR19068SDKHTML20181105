VALUE *  func,
GeData *  retval = nullptr,

Executes a compiled script of a C.O.F.F.E.E. engine, essentially by calling *retval = (*func)(*arg1, *arg2, *arg3). Error information can be retrieved with GeCoffeeGetLastError().

Parameters
[in]cofA C.O.F.F.E.E. engine, either allocated manually or retrieved from GetCoffeeMaster(). The caller owns the pointed C.O.F.F.E.E. engine.
[in]funcThe function entry point. Use GeCoffeeFindGlobalSymbol() to find the function to call. The caller owns the pointed VALUE.
[out]retvalAssigned the return value of the function if not nullptr. The caller owns the pointed GeData.
[out]arg1Used for the first argument of the function if not nullptr. The caller owns the pointed GeData.
[out]arg2Used for the second argument of the function if not nullptr. The caller owns the pointed GeData.
[out]arg3Used for the third argument of the function if not nullptr. The caller owns the pointed GeData.
Returns
true if the execution was successful, otherwise false.
