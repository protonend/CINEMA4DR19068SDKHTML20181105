FILENAME

Definition

FILENAME [id]
{
  [Common flags]
  [DIRECTORY;]
  [SAVE;]
}

Description

Represents Filename objects in a container. Rendered as an edit field with a file selector.

Flags

DIRECTORY;Directory mode.
SAVE;Save mode.

Example

FILENAME VPAMBIENTOCCLUSION_CACHE_FILE_PATH
{
ANIM OFF;
SAVE;
}
