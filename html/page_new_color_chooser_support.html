Supporting the new Color Chooser introduced in R17 needs some changes in plugins code.

Old Preferences

Almost all the preferences for the old Color Chooser have been deprecated:

WPREF_COLOR_SYSTEM_C4D
WPREF_COLOR_SYSTEM_BP
COLORSYSTEM_HSVTAB
COLORSYSTEM_TABLE
COLORSYSTEM_RGB_COLOR
COLORSYSTEM_HSV_COLOR
WPREF_COLOR_HRANGE
WPREF_COLOR_SVRANGE
COLORSYSTEM_RANGE_DEGREE
WPREF_COLOR_QUICK_C4D
WPREF_COLOR_QUICK_BP
WPREF_COLOR_MIX_C4D
WPREF_COLOR_MIX_BP
WPREF_COLOR_SETUPS
WPREF_COLOR_QUICKPRESET
WPREF_COLOR_QUICKPRESET_LAST
WPREF_COLOR_MIXING_1
WPREF_COLOR_MIXING_2
WPREF_COLOR_MIXING_3
WPREF_COLOR_MIXING_4
WPREF_COLOR_SYSTEM_COLORCHOOSER

These preferences are still defined but they are not doing anything in the new Color Chooser.

Only WPREF_COLOR_RGBRANGE is still useful but note that COLORSYSTEM_RANGE_DEGREE has been deprecated.

New Preferences

Here are the preferences to use with the new Color Chooser:

Bool WPREF_COLOR_MODE_RGB // RGB Sliders Mode.
Bool WPREF_COLOR_MODE_HEX // Hexadecimal Color Field.
Bool WPREF_COLOR_MODE_RGB_OLD_SLIDERS // Use Old-Style RGB Sliders.
Bool WPREF_COLOR_MODE_HSV // HSV Sliders Mode.
Bool WPREF_COLOR_MODE_KELVIN // Kelvin Color Temperature Mode.
Bool WPREF_COLOR_MODE_MIXER // Color Mixer Mode.
Bool WPREF_COLOR_MODE_SWATCHES // Color Swatches Mode.
Bool WPREF_COLOR_MODE_SWATCHES_SHOWNAMES // Show Swatches Group Names.
Int32 WPREF_COLOR_MODE_SWATCHES_SWATCH_SIZE // Swatches Size Mode:
COLORSYSTEM_SIZE_SMALL // Small.
COLORSYSTEM_SIZE_MEDIUM // Medium.
COLORSYSTEM_SIZE_LARGE // Large.
Int32 WPREF_COLOR_MODE_SPECIAL // Special Color Mode (these are exclusive each other):
COLORSYSTEM_MODE_SPECIAL_DISABLED // Special Mode disabled.
COLORSYSTEM_MODE_SPECIAL_COLORWHEEL // Color Wheel Mode.
COLORSYSTEM_MODE_SPECIAL_SPECTRUM // Color Spectrum Mode.
COLORSYSTEM_MODE_SPECIAL_PICTURE // Color from Picture Mode.
Int32 WPREF_COLOR_MODE_WHEEL_SIZE // Color Wheel Size:
COLORSYSTEM_SIZE_SMALL // Small.
COLORSYSTEM_SIZE_MEDIUM // Medium.
COLORSYSTEM_SIZE_LARGE // Large.
Int32 WPREF_COLOR_MODE_WHEEL_SWATCH_SIZE // Color Wheel Preview Swatches Size:
COLORSYSTEM_SIZE_SMALL // Small.
COLORSYSTEM_SIZE_MEDIUM // Medium.
COLORSYSTEM_SIZE_LARGE // Large.
Int32 WPREF_COLOR_MODE_SPECTRUM_SIZE // Spectrum Size:
COLORSYSTEM_SIZE_SMALL // Small.
COLORSYSTEM_SIZE_MEDIUM // Medium.
COLORSYSTEM_SIZE_LARGE // Large.
Int32 WPREF_COLOR_MODE_PICTURE_SWATCH_SIZE // Picture Mode Swatches Size:
COLORSYSTEM_SIZE_SMALL // Small.
COLORSYSTEM_SIZE_MEDIUM // Medium.
COLORSYSTEM_SIZE_LARGE // Large.

New Flags

Flags for Color gadgets in dialogs have been added. These flags are meant to be used with GeDialog::AddColorField(), GeDialog::SetColorField() and GeDialog::AddColorChooser():

DR_COLORFIELD_NO_MODE_BUTTONS // Hides the Color Mode buttons.
DR_COLORFIELD_NO_COLORWHEEL // Hides the Color Wheel mode button.
DR_COLORFIELD_NO_SPECTRUM // Hides the Color Spectrum mode button.
DR_COLORFIELD_NO_PICTURE // Hides the Color From Picture mode button.
DR_COLORFIELD_NO_RGB // Hides the RGB sliders mode button.
DR_COLORFIELD_NO_HSV // Hides the HSV sliders mode button.
DR_COLORFIELD_NO_KELVIN // Hides the Kelvin Color Temperature mode button.
DR_COLORFIELD_NO_MIXER // Hides the Color Mixer mode button.
DR_COLORFIELD_NO_SWATCHES // Hides the Swatches mode button.
DR_COLORFIELD_NO_SCREENPICKER // Hides the ScreenPicker mode button.
DR_COLORFIELD_ENABLE_COLORWHEEL // Enables the Special Color Wheel mode (Special modes are exclusive each other: use only one at a time).
DR_COLORFIELD_ENABLE_SPECTRUM // Enables the Special Color Spectrum mode (Special modes are exclusive each other: use only one at a time).
DR_COLORFIELD_ENABLE_PICTURE // Enables the Special Color from Picture mode (Special modes are exclusive each other: use only one at a time).
DR_COLORFIELD_ENABLE_RGB // Enables the RGB sliders mode.
DR_COLORFIELD_ENABLE_HSV // Enables the HSV sliders mode.
DR_COLORFIELD_ENABLE_KELVIN // Enables the Kelvin Color Temperature mode.
DR_COLORFIELD_ENABLE_MIXER // Enables the Color Mixer mode.
DR_COLORFIELD_ENABLE_SWATCHES // Enables the Swatches mode.
DR_COLORFIELD_RGB_HIDE_HEX // Hides the Hexadecimal color field in the RGB Mode.

Settings

Several Color Chooser settings have been deprecated:

BFM_COLORCHOOSER_SYSTEM
BFM_COLORCHOOSER_H_RANGE
BFM_COLORCHOOSER_SV_RANGE
BFM_COLORCHOOSER_QUICKSTORE
BFM_COLORCHOOSER_MIXINGPANEL

The only settings that are still useful are BFM_COLORCHOOSER_RGB_RANGE and BFM_COLORCHOOSER_SYSTEMMESSAGE. Note that in R17 GeDialog::AddColorChooser() has now a 'settings' parameter.

New Drag Type

Finally a new DRAGTYPE has been added for dragged color arrays: DRAGTYPE_RGB_ARRAY.
