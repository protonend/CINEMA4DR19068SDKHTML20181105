Foundation Classes Overview

About

This page presents the most fundamental classes and concepts of the Cinema 4D API. These classes and their functions are used all over the API and are involved in all operations.

To create new instances of complex data types Cinema 4D's memory management system should be used. See Entity Creation and Destruction Manual.

Many classes of the Cinema 4D API are based on C4DAtom, GeListNode and BaseList2D. These three classes implement the most fundamental functionality:

  • C4DAtom Manual
  • GeListNode Manual
  • BaseList2D Manual

Related classes are:

  • GeListHead is a class used as a the root of object lists and trees. See GeListHead Manual.
  • A DescID element is used to identify the parameters of C4DAtom based objects. See DescID Manual.
  • An AtomArray can be used to store pointer to C4DAtom based objects. See AtomArray Manual.
  • A GeMarker is a unique marker that is used to identify BaseList2D based elements. See GeMarker Manual.
