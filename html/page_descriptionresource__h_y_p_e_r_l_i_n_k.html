HYPERLINK

Definition

HYPERLINK [id]
{
  [Common flags]
  [STATIC_TEXT text;]
  [LINK_DEST dest;]
  [IS_LINK;]
}

Description

Represents HyperLinkData objects in a container, rendered with a HyperLinkCustomGui.

Flags

ALPHA;Editable alpha gradient.
STATIC_TEXT text_id;The link text string ID.
LINK_DEST dest_id;The link URL string ID.
IS_LINK;The link is underlined, and open URL on click.

Example

HYPERLINK MY_LINK { STATIC_TEXT MY_LINKTEXTID; LINK_DEST MY_LINKURLID; IS_LINK; }
