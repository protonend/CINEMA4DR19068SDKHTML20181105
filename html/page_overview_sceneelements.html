Scene Elements Overview

About

A 3D scene is composed of objects of different types like polygon meshes, lights and cameras. Additionally the scene graph of Cinema 4D can contain generators and deformers.

  • BaseObject is the base class for all objects, generators, deformers, etc. See BaseObject Manual.
  • Scene objects use a certain way to handle their position. See Freeze Transformation.
  • A CameraObject represents a scene camera. See CameraObject Manual.

Other BaseObject based objects like lights etc. can be edited through their parameters.

Tags are used to add data or functionality to such objects:

  • BaseTag and VariableTag are base classes for tags. See BaseTag and VariableTag Manual.

Notable tags are:

  • The TextureTag, see TextureTag Manual.
  • The UVWTag, see UVWTag Manual.
  • The NormalTag, see NormalTag Manual.
  • The VertexColorTag, see VertexColorTag Manual.
