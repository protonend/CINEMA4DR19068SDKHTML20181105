ColorSwatchData Class Reference
Library » ColorChooser Library

#include <lib_colorchooser.h>

Detailed Description

This class handles the Swatch Data stored globally, in a BaseDocument or a preset. It holds 2 kinds of groups:

  • A global color group that is shared between all Cinema 4D documents and has special methods to handle it.
  • Document-based color groups stored in a Cinema 4D document.

◆ LoadGlobalGroup()

Bool LoadGlobalGroup ( )

Loads global colors. These colors are global to all Cinema 4D documents, are used in the current working Cinema 4D session and preserved between Cinema 4D sessions if the option WPREF_COLOR_MODE_SWATCHES_REMEMBER_GLOBAL is true.

The GUI option is in Cinema 4D preferences / Units / Color Chooser / Default Set / Swatches Mode / Remember Global Swatches. If the option is false, when Cinema 4D is restarted, the default colors will be loaded.

See also

Returns
true if successfull, otherwise false.

◆ LoadDefaultGlobalGroup()

Bool LoadDefaultGlobalGroup ( Bool  ignoreFile = false)

Loads default global colors. These colors are loaded when Cinema 4D starts and if the preference option WPREF_COLOR_MODE_SWATCHES_REMEMBER_GLOBAL is false.

The GUI option is in Cinema 4D preferences / Units / Color Chooser / Default Set / Swatches Mode / Remember Global Swatches.

Note
Default global colors are stored in the file "defaultswatches" in the preferences folder. If that file is missing, a hardcoded default color set will be loaded instead.
