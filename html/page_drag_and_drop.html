Drag and Drop

Drag and drop messages can be used to implement dragging and dropping of all kinds of Cinema 4D elements in the GUI. They can also be used for private drag and drop operations.

Distribution

Drag and drop messages are sent directly to GeDialog::Message and GeUserArea::Message, i.e. there are no special encapsulations.

Structure

Drag and drop messages are stored in BaseContainer objects. The message ID of the container is BFM_DRAGRECEIVE.

See BFM_DRAG

Receiving a Drop

To be able to receive drops from the Cinema 4D GUI listen for the BFM_DRAGRECEIVE message in your dialog or user area.
When received there are several values to check. First the BFM_DRAG_LOST flag:

if (msg.GetInt32(BFM_DRAG_LOST))
{
// No longer the target of the drag operation.
// Remove or reset any help text/lines.
}

Otherwise check where the mouse is. Use the GeUserArea::CheckDropArea() or GeDialog::CheckDropArea() convenience functions to check against each dialog item:

if (CheckDropArea(DLG_ITEM, msg, true, true)
{
// The mouse is in DLG_ITEM.
}

Note that it is possible to check against groups as well, so that the sub-components are not checked unnecessarily:

if (CheckDropArea(dlg, DLG_GROUP, msg))
{
if (CheckDropArea(DLG_ITEM1, msg, true, true)) {}
if (CheckDropArea(DLG_ITEM2, msg, true, true)) {}
...
}

To extract the information about the dragged object use GeDialog::GetDragObject() or GeUserArea::GetDragObject():

Int32 type = 0;
void *object = nullptr;
GetDragObject(msg, &type, &object);
switch (type)
{
case DRAGTYPE_OBJECT:
{
BaseObject *obj = static_cast<BaseObject*>(object);
...
}
break;
case DRAGTYPE_TAG:
case DRAGTYPE_MATERIAL:
...
default:
...
}

If the user just released the mouse the BFM_DRAG_FINISHED flag is set:

if (msg.GetInt32(BFM_DRAG_FINISHED))
{
...
}

If the user has not finished the drag yet use GeDialog::SetDragDestination() or GeUserArea::SetDragDestination() to set the mouse cursor:

if (dragAcceptable)
{
return SetDragDestination(MOUSE_INSERTCOPY);
}
else
{
return SetDragDestination(MOUSE_FORBIDDEN);
}

Starting a Drag

Drags can only be started from within user areas. This is done with the GeUserArea::HandleMouseDrag() function.
