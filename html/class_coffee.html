Coffee Class Reference

#include <c4d_coffee.h>

Detailed Description

The C.O.F.F.E.E. engine class. Allows to extend the language and to add objects to the environment.

Note
Has to be created with Alloc() and destroyed with Free(). Use AutoAlloc to automate the allocation and destruction based on scope.

◆ InstallErrorHook()

void InstallErrorHook ( COFFEE_ERRORHANDLER *  priv_hndl,
void *  priv_data 
)

Installs an error handler that is used instead of the standard Cinema 4D C.O.F.F.E.E. console output.
If the error handler returns false, then no further Cinema 4D output is generated, otherwise Cinema 4D prints the standard console stuff. Example:

static Bool CofError(void* priv_data, const BaseContainer &bc)
{
GePrint(String("[FAIL] Pos ") + String::IntToString(bc.GetInt32(3)) + String(" : ") + bc.GetString(5));
return false;
}
cof->InstallErrorHook(CofError, nullptr);
See also
COFFEE_ERRORHANDLER callback for more information.
Parameters
[in]priv_hndlThe error handler hook.
[in]priv_dataThe private data that is passed to the hook. The caller owns the pointed data.

◆ CompileFile()

Bool CompileFile ( const Filename &  fn,
Bool  tofile 
)

Compiles a C.O.F.F.E.E. source code file and optionally creates the compiled binary file.
Example:

// Compiles the selected source code file and writes the compiled binary
AutoAlloc<Coffee> cof;
if (!cof) return false;
Filename fn;
if (fn.FileSelect(FILESELECTTYPE_ANYTHING, FILESELECT_LOAD, "Select C.O.F.F.E.E. File"))
{
if (cof->CompileFile(fn, true))
GePrint("Success");
else
GePrint("Failed");
}
Parameters
[in]fnThe filename for the C.O.F.F.E.E. source code file.
[in]tofileIf true a compiled binary file will be written at the same path as the source code file.
Returns
true if successful, otherwise false.
