COFFEE_VTYPE_LONG 

Int32. Use VALUE::GetInt32() to access the data.

COFFEE_VTYPE_FLOAT 

Float. Use VALUE::GetFloat() to access the data.

COFFEE_VTYPE_VECTOR 

Vector. Use VALUE::GetVector() to access the data.

COFFEE_VTYPE_VOID 

void*. Used for unknown or foreign classes/objects, where only the pointer is known, for example in the connection to C++ classes.

COFFEE_VTYPE_BYTES 

Bytes. Use VALUE::GetSize() and VALUE::GetBytes() to access the data.

COFFEE_VTYPE_STRING 

String. Use VALUE::GetString() to access the data.

COFFEE_VTYPE_CLASS 

Class. Can be used with C4DAtom::IsInstanceOf(). Cannot currently be used to instantiate objects.

COFFEE_VTYPE_OBJECT 

Object. Used for things created with new() in C.O.F.F.E.E. that are not arrays. Use VALUE::GetObjMember() to access members.

COFFEE_VTYPE_ARRAY 

Array. Use VALUE::GetArrayMember() to access the array.
