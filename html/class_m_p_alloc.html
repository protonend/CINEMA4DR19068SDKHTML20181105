Detailed Description

template<class TYPE>
class MPAlloc< TYPE >

Advanced multi-threading array class.

See also
menutest.cpp SDK example.
Warning
Array types are not allowed: e.g. MPAlloc<Char> is fine, MPAlloc<Char[1000]> will not work.
