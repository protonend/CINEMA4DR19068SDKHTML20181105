Plugin Types

Here are the available plugin hooks in Cinema 4D:

Command Plugins

  • CommandData - A hook to create custom commands.

Tag Plugins

  • TagData - A hook to create a custom tag.

Object Plugins

  • ObjectData - A hook to create a custom object type; generators, deformers, splines and particle modifiers.

Tool Plugins

  • ToolData - A hook to create a custom editor tool.
  • BrushToolData - A hook to create custom CA brushes.
  • DescriptionToolData - A hook to create modeling tools.
  • SculptBrushModifierData - A hook to create sculpt brush modifiers.
  • SculptBrushToolData - A hook to create custom sculpt brushes.

Snap Plugins

  • SnapData - A hook to create custom snap modes.

Animation Plugins

  • CTrackData - A hook to create custom tracks for the time-line.

Shader Plugins

  • ShaderData - A hook to make 2D shaders.

Material Plugins

  • MaterialData - A hook to make materials/volume shaders.

Export/Import Plugins

  • BitmapSaverData / BitmapLoaderData - A hook to make import/export filters for image formats.
  • SceneSaverData / SceneLoaderData - A hook to make import/export filters for 3D formats.

Scene Hook Plugins

  • SceneHookData - A hook that is executed during various stages of the pipeline.

Video Post Plugins

  • VideoPostData - A versatile hook that is executed during rendering.

Fallof Plugins

  • FalloffData - A hook to make custom falloffs.

Message Plugins

  • MessageData - A hook to receive plugin messages.

Custom GUI/DataType Plugins

  • CustomDataTypeClass, ResourceDataTypeClass - Creates a custom data type that can be used in containers and descriptions.
  • CustomGuiData - Creates a custom GUI that can be used in dialogs and descriptions.

Preference Plugins

  • PrefsDialogObject - A hook to register a new preference category in the Cinema 4D Preferences dialog.

GraphView Operator Plugins

  • GvOperatorData - Creates custom GraphView operators.

Node Plugins

  • NodeData - Creates custom nodes.
