Macro Definition Documentation

◆ MATASSIGN_TAG_ID

#define MATASSIGN_TAG_ID

If the user drags an object into the list a tag of this ID is created. (Default is Ttexture.)

Int32 Material assign tag ID.

◆ MATASSIGN_CONTAINER_ID

#define MATASSIGN_CONTAINER_ID

If the user drags an object into the list the tag created gets a link to the object at this ID in its container. (Default is TEXTURETAG_MATERIAL.)

Int32 Material assign container ID.

◆ MATASSIGN_MATERIAL_ID

#define MATASSIGN_MATERIAL_ID

Int32 Material assign material ID. The list must belong to a material with this type. (Default is Mmaterial.)
