Here we'll walk you through the process of creating a new plugin project in Apple's Xcode by cloning the cinema4dsdk example project. The screenshots mostly show Xcode 6.0.1, but it virtually works the same in any version downto Xcode 4.

Setup Procedure

Step 1 - Project Directory Structure

You start with just the standard folder structure, containing a res folder with your symbols, icons, and string tables, and a source folder, containing your C++ sources (subfolders are of course possible). Inside the res folder you may or may not have dialogs and description subfolders, which would contain your .res files and their respective headers, as well as string_XX folders containing the string tables (.str) with translations for your dialogs and/or descriptions. See Description Resource and Dialog Resource for further information.

Step 2 - Copy and Rename cinema4dsdk.xcodeproj

Take a look into the cinema4dsdk folder and locate the Xcode project file cinema4dsdk.xcodeproj.

Copy&paste the project into your plugin's folder and rename it as you wish, using the title of your plugin might be a good idea.

Step 3 - Delete Example Sources From the Xcode Project

Open the project in Xcode. Select all the SDK files that are under the source folder on the left side of the window...

...and remove them by pressing the Del key. If you already have source files in your directory structure, a dialog may pop up, click "Remove Reference" and not "Move to Trash".

Step 4 - Add Your Sources to the Project

Drag&Drop your source files (including subfolders) from the Finder into the source folder in your project.

A dialog pops up. Don't change any settings, just click the "Finish" button. Your project now contains all the sources, and even resembles the original folder structure.

Step 5 - Rename Your Product

Select the project (on the top of the source/libs/products tree), then select the project in the second column (do not select the target cinema4dsdk! [1]), then search for "product name" in the Build Settings. Change the product name. This will determine the filename of the plugin binary. Don't worry about the filename under the "Products" folder on the left side not adapting to the new product name, that seems to be a bug that has been in Xcode since ages.

Step 6 - Rename the Scheme

Click on the Scheme Selector on top of the Xcode window, just right beneath the Run and Stop buttons. Make sure you click on the left half of the Scheme Selector. From the menu that pops up, choose "Manage Schemes...".

In the scheme list, select the cinema4dsdk scheme. Double-click on cinema4dsdk and change the name to something else. Once again, using your plugin's title would be a good idea. Then, click "OK".

In the Scheme Selector, make sure that the entry with your plugin's name and My Mac is selected. With SDK versions prior to R16, you also need to make sure, the 64-bit entry is selected.

Step 7 - Rename the Target

We're not done renaming stuff yet. Double-click on the target cinema4dsdk and change the name to - you guessed it - your plugin's name.

Step 8 - Add Additional Include Directories

If there are any additional include directories where you have stored header files, you must add them to the project's header search paths. Select the project from the center column (do not select the target cinema4dsdk!), then search for "header search" in the Build Settings. Double-click on the entry "Header Search Paths" to edit them.

A list dialog will pop up. To add a header search path, click the "+" button, and enter the path into the new list item (you can use absolute paths, or paths relative to the project location). If you also want subfolders to be searched for header files, choose "recursive" from the little selector on the right.

Step 9 - Correct Build Target

If this step is necessary or not seems to depend on Xcode versions. Enter the scheme settings (not the scheme manager) either via menu Menu: Product → Scheme → Edit Scheme... or a bit quicker via Cmd + <. Select Build on the left side, there you may see a reference to cinema4dsdk highlighted in red. Select the line cinema4dsdk and remove it by pressing the "-" button.

The press the "+" button to add a new target reference.

In the end it should look like this:

That should be it. Close the Xcode window to save the project (as there is no "Save Project" menu option in Xcode).

Footnotes

[1] If you want to change build settings for your project, always select the project in the center column and not any of the targets. If you select the project, your changes will apply to the whole project including all targets. If you select a target, the changed setting will only apply to this specific target.
