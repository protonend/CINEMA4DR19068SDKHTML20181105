Media Manual

About

Cinema 4D plugins often have to handle various media files and media data.

  • A basic bitmap with alpha data can be stored in a BaseBitmap. See BaseBitmap Manual.
  • A bitmap with multiple layers can be stored as a MultipassBitmap. See MultipassBitmap Manual.
  • GeClipMap is a utlity class to perform drawing operations on a bitmap. See GeClipMap Manual.

The image data stored in movie files can be access with these classes:

  • MovieLoader allows to read image data from a movie file. See MovieLoader Manual.
  • MovieSaver allows to save image data to a movie files. See MovieSaver Manual.
